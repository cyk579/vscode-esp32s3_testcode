# ESP32-S3 三轮小车四路红外巡线程序

本工程使用 ESP-IDF 控制三路电机 Motor A、Motor B、Motor D，并读取四路数字红外传感器；同时读取 HC-SR04 超声波并驱动 LQ_TFT18SPIV33 SPI 彩屏。程序支持巡线、前方避障和实时状态显示：巡线控制周期约 10 ms，超声波约 100 ms 更新一次，TFT 每 100 ms 刷新一次。

## 引脚对应

### 四路红外模块

程序默认按车体实际方向解释传感器：本车 OUT1 在右侧、OUT4 在左侧，代码通过反向映射后再按左到右计算误差。

| 红外模块 | ESP32-S3 | 程序位置 |
| --- | --- | --- |
| OUT1 | GPIO41 | 最右（原始通道） |
| OUT2 | GPIO42 | 右中（原始通道） |
| OUT3 | GPIO2 | 左中（原始通道） |
| OUT4 | GPIO1 | 最左（原始通道） |

如果实际传感器左右方向与当前车体相反，把 `main/main.c` 中的：

```c
#define REVERSE_SENSOR_ORDER 0
```

在 `0` 和 `1` 之间切换。当前这台小车已经设置为 `1`。

### TB6612 四路驱动板

| ESP32-S3 | 驱动板信号 | 用途 |
| --- | --- | --- |
| GPIO4 | PWMB | Motor B PWM |
| GPIO6 | BIN1 | Motor B 方向 1 |
| GPIO5 | BIN2 | Motor B 方向 2 |
| GPIO8 | STBY | 驱动板总使能，高电平工作 |
| GPIO9 | PWMA | Motor A PWM |
| GPIO12 | AIN1 | Motor A 方向 1 |
| GPIO10 | AIN2 | Motor A 方向 2 |
| GPIO16 | PWMD | Motor D PWM |
| GPIO7 | DIN1 | Motor D 方向 1 |
| GPIO15 | DIN2 | Motor D 方向 2 |
| GPIO17 | ADC | 本巡线程序暂不使用 |

### HC-SR04 超声波

| ESP32-S3 | HC-SR04 | 用途 |
| --- | --- | --- |
| GPIO18 | TRIG | 10 us 触发脉冲（必须与实物接线一致） |
| GPIO11 | ECHO | 回波脉宽测距（必须与实物接线一致） |
| 5 V | VCC | 普通 HC-SR04 的推荐供电 |
| GND | GND | 必须共地 |

程序每 `100 ms` 只触发一次测距，并在连续三次有效结果间取中值；这符合 HC-SR04 的最小重触发间隔，也不会阻塞 `10 ms` 的巡线控制。经中值滤波的距离小于 `7 cm` 时立即进入避障；左移中的新测距大于 `10 cm` 时记录左移时间并停止左移。无回波时显示 `---`，串口会输出可诊断状态。

超声波首次测试时，先断开障碍物，打开串口并在探头前约 `10 cm` 放一块平板。`US OK ... dist=...` 表示程序、引脚和模块均已工作；`US NO_ECHO` 表示触发后 ECHO 从未拉高，应检查模块供电、TRIG/ECHO 接线和 GPIO18/11 映射；`US ECHO_HIGH` 表示 ECHO 长时间高电平，应检查 ECHO 电平转换或接线短路；`US OUT_OF_RANGE` 表示已收到回波，但距离不在 `2–400 cm` 的有效范围。

若需要先排除程序或 GPIO 选错：**断开超声波模块的 TRIG、ECHO 两根线**，仅用一根杜邦线短接 ESP32 的 `GPIO18` 与 `GPIO11`，复位后应看到 `US OUT_OF_RANGE`（10 us 触发脉冲形成约 `0.2 cm` 的模拟回波）。这证明程序、这两个 ESP32 引脚和串口诊断链路正常；随后拆掉短接线并接回模块。模块仍显示 `NO_ECHO` 时，就是模块供电、接线或模块本体的问题。切勿在模块的 ECHO 仍连接时做此短接。

本次超声波排查使用 `GPIO18` 作为 `TRIG`、`GPIO11` 作为 `ECHO`；实物必须按此接线。引脚表中这两脚原标为云台信号，因此测试时云台不能同时接在 GPIO11/18。普通 HC-SR04 应接 `5 V` 供电，`ECHO` 的 5 V 高电平必须经分压或电平转换后再接入 ESP32-S3；只有明确标为 3.3 V 版本的模块才能接 3.3 V。

### TFT SPI 彩屏

`LQ_TFT18SPIV33` 按常见 1.8 英寸 `ST7735` 控制器、`128x160` 分辨率初始化。引脚如下：

| ESP32-S3 | TFT | 用途 |
| --- | --- | --- |
| GPIO13 | SCK | SPI 时钟 |
| GPIO14 | SDI | SPI MOSI |
| GPIO21 | D/C | 命令/数据 |
| GPIO47 | CS | 片选 |
| GPIO38 | RST | 硬件复位 |
| 3.3 V | 3V3/VCC | 屏幕电源 |
| GND | GND | 必须共地 |

屏幕显示距离、红外掩码、误差、转向量、A/B/D 电机输出和当前模式（`LINE`、`AVOID-L`、`AVOID-F`、`AVOID-R`、`END`）。如果实物不是 ST7735 或分辨率不是 128x160，只需调整 `main/tft_st7735.c` 的初始化和宽高常量。

ESP32、红外模块、驱动板和电机电源必须共地。红外模块数字输出接 ESP32 时必须是 3.3 V 电平；若模块 OUT 会输出 5 V，需要电平转换，不能直接接 GPIO。

## 第一次调试：检查传感器

先架空车轮并打开串口监视器，把黑线依次放在每个探头下方。程序上电后在首次检测到黑线前电机保持为 0，日志中的 `ACTIVE` 示例为：

```text
ACTIVE=1000
ACTIVE=0100
ACTIVE=0010
ACTIVE=0001
```

`ACTIVE` 从左到右对应车体实际的 OUT4、OUT3、OUT2、OUT1；`1` 表示检测到黑线。`RAW` 才按接口 OUT1、OUT2、OUT3、OUT4 排列。本车模块实测为白底高电平、黑线低电平，因此程序默认：

```c
#define IR_ACTIVE_LEVEL 0
```

如果更换模块后逻辑相反（黑线输出高电平），再改为 `1`。也可调节红外板上的电位器，让每一路的指示灯在黑线与白底之间可靠翻转。

## 启用巡线

程序复位后等待 2 秒。至少一个探头检测到黑线后才允许电机启动；全白时上电不会盲目运动。

控制策略：

- `1001`（OUT2/OUT3 在黑线上）：执行经过 A/D 配平的固定直行；
- 黑线偏向一侧：先对四路加权误差低通，再送入 PID；转向量每个周期受限变化，避免左右输出突变；
- 黑线越靠近最外侧，转向量越大，同时前进基量逐步降低到弯道下限；
- 完全丢线：先沿最后偏差方向继续前进约 `100 ms`，再以较低前进量弧线搜索，避免读空一次就原地停住。

上电后如果四路都没有检测到线，程序保持电机 PWM 为 0；必须先让至少一个探头检测到线，巡线控制才会开始。

## 主要调参项

都在 `main/main.c` 顶部：

| 参数 | 默认值 | 调整方法 |
| --- | ---: | --- |
| `STRAIGHT_A_SPEED` | 30 | 直行时右前 Motor A 的输出幅值 |
| `STRAIGHT_D_SPEED` | 30 | 直行时左前 Motor D 的输出幅值，与 A 保持一致 |
| `CURVE_A_SPEED` | 20 | 转弯时 Motor A 的最小前进分量 |
| `CURVE_D_SPEED` | 20 | 转弯时 Motor D 的最小前进分量，与 A 保持一致 |
| `TURN_MAX` | 12 | 外侧检测或丢线搜索时的最大旋转分量 |
| `MAX_OUTPUT` | 30 | 任一电机最终输出上限 |
| `TURN_SIGN` | 1 | 若所有左右纠偏与实车相反，改为 `-1` |
| `LOST_LINE_FORWARD_MS` | 100 | 丢线后保持前进的最长时间 |
| `START_KICK_OUTPUT` | 30 | 电机停止后起转或换向时的短时增强输出 |
| `START_KICK_CYCLES` | 2 | A/D 起转增强持续约 20 ms；B 转向轮不使用强制起转，避免突兀摆动 |
| `FILTER_SAMPLES` | 5 | 每周期多数采样次数 |
| `FILTER_STABLE_CYCLES` | 2 | 新方向连续出现两次才确认 |
| `PID_KP` | 4 | 比例增益，决定当前偏差的纠偏强度 |
| `PID_KI` | 1 | 积分增益，修正持续偏差，并带积分限幅 |
| `PID_KD` | 2 | 微分增益，抑制摆动，微分值经过平滑 |
| `PID_DEADBAND` | 3 | 小误差死区，避免对对称组合频繁修正 |
| `PID_SCALE` | 10 | PID 输出缩放因子 |
| `PID_INTEGRAL_LIMIT` | 30 | 积分限幅，防止误差长期累积 |
| `ERROR_FILTER_DIVISOR` | 2 | 误差低通强度；增大更平滑，但急弯响应会更慢 |
| `TURN_SLEW_STEP` | 3 | 每 `10 ms` 转向量最多变化值；增大响应更快，减小更平滑 |

## 赛道适配说明

当前使用的 LQ_R4CHVB 模块为黑线低电平、白底高电平，因此 `IR_ACTIVE_LEVEL=0`。车体从左到右是 OUT4、OUT3、OUT2、OUT1，代码通过 `REVERSE_SENSOR_ORDER=1` 转换为内部左到右顺序。

控制器每周期进行 5 次多数采样，新方向连续出现两次后确认；PID 输入会先低通，输出再限速变化。控制器不再回放过期的方向历史，因此越过中心线后不会继续执行旧方向的纠偏。完全丢线时先前进、再低速弧线搜索，避免车辆停在原地。

左转时，右前 Motor A 增加前进分量、左前 Motor D 减少前进分量；右转时相反。Motor B 保留原来的旋转方向，只提供转向分量。

串口日志中的 `RAW` 按 OUT1 到 OUT4 排列；OUT2/OUT3 压在线上时显示 `RAW=1001`。`ACTIVE` 按车体左到右排列，以 `1` 表示检测到黑线，此时为 `0110`。`err` 负数表示线在左侧、正数表示线在右侧；`motor[A,B,D]` 是三个电机的有符号 PWM 百分比。

## 三轮方向校准

根据当前底盘描述，OUT4 左侧是 Motor D，OUT1 右侧是 Motor A，Motor B 位于后方。直行时高层混控输出 A 为负、D 为正、B 为 0；当前程序使用 `MOTOR_D_SIGN=-1` 完成左前轮方向校准。转弯时 A/D 使用相反的差速修正，B 提供旋转分量。第一次运动测试必须架空车轮。

当日志稳定显示 `RAW=1001 ACTIVE=0110 err=0` 时，程序固定输出 `motor[A,B,D]=[-30,0,30]`。`MOTOR_D_SIGN=-1` 会在驱动层反转 D；日志显示的是混控层数值。两侧幅值保持相同，直线偏差交给 PID 在传感器离开中心后修正。

如果某个电机的实际转向相反，修改对应项：

```c
#define MOTOR_A_SIGN 1
#define MOTOR_B_SIGN 1
#define MOTOR_D_SIGN -1
```

把相应的 `1` 改为 `-1`。如果传感器显示线在右边，但车辆实际向左修正，优先确认 OUT1/OUT4 的物理左右顺序；确认顺序无误后再校准电机方向。

## 建议调试顺序

1. 架空轮子，让 OUT2/OUT3 对准黑线，确认日志为 `1001/0110`，A/D 反向旋转，B 不动。
2. 放在长直道上，只调整 `STRAIGHT_A_SPEED` 和 `STRAIGHT_D_SPEED`，先解决机械直行。
3. 测试缓弯，先调整 `PID_KP`，有持续偏差再调整 `PID_KI`，摆动明显再提高 `PID_KD`。
4. 测试 60/90 度弯；纠偏过强先降低 `PID_KP`，丢线转向不足再提高 `TURN_MAX`。

开始地面测试时应预留断电空间；若传感器读数异常或小车转向与误差方向相反，立即断开电机电源，不要直接提高 PWM。

## 避障流程

检测到前方障碍后，程序依次执行：

1. 经超声波中值滤波后检测到距离小于 `7 cm`，立即停止巡线前进。
2. `AVOID-L`：横向左移，直到新测距大于 `10 cm`，并记录实际左移时间。若测距异常，最长左移 `2.5 s` 后进入后续流程。
3. `AVOID-F`：沿车头方向前进 `1 s`。
4. `AVOID-R`：横向右移；当右移时间达到前面记录的左移时间，或中间两路红外已稳定检测到黑线（`ACTIVE=0110`），任一条件成立即结束右移。外侧探头单独碰线不会过早结束横移。
5. 恢复 `LINE` 巡线。

横移使用三轮全向混控，当前 `lateral>0` 定义为左移；若实车方向相反，将 `drive_vector()` 中三个 `lateral` 项整体取反即可。避障阶段仍持续更新屏幕和串口状态。

终点判定只使用未经控制滤波的原始电平：当前模块黑线为低电平时，四路连续读到 `RAW=0000` 才开始确认。程序要求此前已稳定跟线至少 `END_ARM_MS=80 ms`，且转向量不大于 `END_TURN_MAX=8`；随后 `RAW=0000` 连续 `20 ms` 即先刹车，并在持续 `END_CONFIRM_MS=80 ms` 后进入永久 `END` 状态。若这是转弯时的短暂黑线，读数离开 `0000` 后会立即恢复巡线，不会永久误停。
